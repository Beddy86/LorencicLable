**Deutsch.** Artikelnummer eingeben, Etikett mit Foto, großer Artikelnummer, Code-128-Barcode und Bezeichnung als PDF drucken. Läuft im Browser (auch am Handy) oder als Windows-Programm. Formate: 16,5 × 6,3 cm, Regalstopper, Mini, Avery-Bögen, A4, A5, eigene Größe, Sammeletiketten.
→ [Anleitung auf Deutsch](README.de.md)

**English.** Enter an article number and get a printable PDF label with photo, large article number, Code 128 barcode and description. Runs in the browser (phone too) or as a Windows program. Formats: 16.5 × 6.3 cm, shelf stopper, mini, Avery sheets, A4, A5, custom size, collective labels.
→ [Guide in English](README.en.md)

**Hrvatski.** Unesite broj artikla i dobijte PDF etiketu s fotografijom, velikim brojem artikla, Code 128 barkodom i opisom. Radi u pregledniku (i na mobitelu) ili kao Windows program. Formati: 16,5 × 6,3 cm, stopper za policu, mini, Avery arci, A4, A5, vlastita veličina, zbirne etikete.
→ [Upute na hrvatskom](README.hr.md)
